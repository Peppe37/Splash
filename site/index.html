Light by design

Three ways onto your desktop. The lightest one that fits.

A wallpaper is on all day, next to your real work. So Splash puts a scene on the desktop in the cheapest way the scene allows, and the app you design it in is a separate window you can close.

Still

One picture. Nothing runs.

The scene is drawn once at full quality and set as your real macOS wallpaper. No process, no CPU, no memory.

0processes
0%CPU
Loop

A recorded loop.

Splash records one seamless loop and the system's video decoder plays it. No web view, no drawing.

~14 MBrunner memory
~1%runner CPU
Live

Drawn in real time.

For scenes that react to something. It pauses when covered, on Low Power Mode, when the screen sleeps and when the Mac gets hot.

~170 MBwith web processes
~7%of one core

Measured once, on one MacBook Pro with Apple silicon, a debug build, a simple scene at 30 fps. System decoders and the GPU are not counted. Treat them as a rough guide, not a benchmark.

The app

Designed for quiet, not for show.

Your scenes as live pictures. A large preview, a few honest controls, versions you can go back to. The runner sits in the menu bar and does nothing until the system tells it something changed.

Optional AI

Describe it. Draw on it. Use the agent you already have.

Splash never asks for an API key. It runs the agent CLI you are already signed in to, inside the scene's folder. Draw on the preview, pin a comment, and the agent changes only what you pointed at. Every request saves a version first.

What works today

Claude Code is tested end to end. Codex is wired up but not tested yet. OpenCode is switched off: in testing it edited files outside the scene, so it stays off until that is understood.

Agents run with your own login and permissions. Splash tells them to touch only the scene folder and shows what they do, but it cannot sandbox them. A scene is plain HTML, CSS and JavaScript in a folder you own: you can read it, edit it, or version it yourself.

Presets

Start from something that already moves.

Every preset is a normal scene: copy it, change it with the controls, or hand it to an agent.

A scene is a folder

Small, readable, yours.

A scene is a manifest and a web page. Controls, loop length and permissions are declared in the manifest, and a linter checks the rest, for people and for agents.

// scene.json
{
  "id": "aurora",
  "tiers": ["baked", "live"],
  "loopSeconds": 24,
  "params": [{ "key": "colorA", "type": "color", "default": "#27e1a0" }]
}

// index.html
const angle = TAU * splash.time / LOOP;   // same clock for live, loop and still
ctx.fillStyle = splash.params.colorA;

Install

Get Splash.

Splash is pre-alpha. There may be no download yet; until there is, build it from source. Needs macOS 14 or later.

From the DMG

  1. Download

    Get the latest .dmg from the button above, open it and drag Splash to Applications.

  2. Open it the first time

    The app is not notarized yet, so macOS asks. Control-click Splash, choose Open, then Open again. Or go to System Settings, Privacy & Security, and choose Open Anyway.

  3. Pick a preset and press Apply

    You can close the window: the wallpaper keeps going in the menu bar.

# from source (Xcode 16 or later)
$ git clone https://github.com/Peppe37/Splash.git
$ cd Splash
$ swift build
$ .build/debug/splash-editor

# or the command line only
$ .build/debug/splash presets
$ .build/debug/splash init my-scene --preset aurora

Questions

Good to know.

Is it free?

Yes. Splash is open source under the GPL-3.0. A few paid extras that need servers, such as cloud features, may come later. The code in this repository stays GPL-3.0.

Does it use my AI API key?

No. Splash has no API key field. The AI feature runs an agent CLI you already installed and signed in to (Claude Code works today), in the scene's folder. What you type and any drawing you send go to that agent, as with any use of it.

Will it drain my battery?

A still wallpaper costs nothing and a loop costs very little. A live scene pauses on Low Power Mode by default, lowers its frame rate on battery, and stops when covered, when the screen sleeps or locks, and when the Mac is hot. You can change these in Settings.

Does it replace my current wallpaper?

While a scene is applied, Splash sets a picture of it as your wallpaper, so Mission Control and new displays match. It remembers the wallpaper you had, and "Put back my previous wallpaper" restores it. A dynamic or Aerial wallpaper can only be restored as a picture.

Why is a moving wallpaper a window?

macOS has no public way to play an animation as the wallpaper itself, so Splash puts a window at the desktop level, under your icons and windows. To limit the side effects it also sets a still picture as the real wallpaper, and the runner stays out of the Dock and the app switcher.

Which Macs?

macOS 14 Sonoma or later.
