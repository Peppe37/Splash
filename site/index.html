What is it?

Splash is a free and open-source app that puts animated and procedural wallpapers on your Mac. A wallpaper is a small folder with a web page and a few controls: start from a preset, change it, or describe what you want to an AI agent you already use. It runs in a tiny background process, so you forget it is there.

Alpha Splash is in early development. Expect rough edges and breaking changes between versions.

Features

Three ways onto the desktop

Still (one picture, nothing runs), Loop (a recorded video, played by the system) or Live (drawn in real time). Splash uses the lightest one the scene allows.

Presets and controls

Aurora, waves, stars, ribbons, soft gradients and a dusk. Change colours and speed with live controls, and see it in a large preview.

AI, with your own agent

Describe a change in words. Splash runs the agent CLI you are already signed in to (Claude Code today), in the scene's folder. No API key.

Draw, comment, attach

Draw on the preview and pin comments, or drop in images, SVGs and videos: to use in the scene, like a character, or as a reference. The agent changes only what you pointed at.

Versions you can go back to

A version is saved before every AI change, so any change can be undone.

Light on battery

It pauses when covered, when the screen sleeps or locks, on Low Power Mode and when the Mac is hot, and lowers its frame rate on battery.

Your own wallpaper stays safe

Splash remembers the wallpaper you had and can put it back. A picture of the scene is also set as the real wallpaper, so Mission Control and new displays match.

Updates in one click

When a new version is out, one button downloads it, checks it and restarts the app, keeping your permissions.

Command line

splash makes pictures and loops, checks a scene and asks an agent from a terminal, with the same engine as the app.

The app

Install

Requires macOS 14 or later. Download the latest build from the Releases page, open the DMG and drag Splash to Applications. Then follow the first launch guide below: macOS will block the app the first time.

With Homebrew, one command (it also skips the first-launch warning):

brew install --cask Peppe37/tap/splash

Prefer building it yourself? Install xcodegen, run xcodegen generate and open Splash.xcodeproj, or run swift build. See the README.

First launch: allowing the app

Splash is not notarized by Apple yet (that requires a paid developer account), so macOS shows a warning saying it cannot verify the app. This is expected. Here is how to open it:

  1. Open Splash from Applications. A message says it could not be opened. Click Done (do not click “Move to Trash”).
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the Security section. You will see “Splash.app was blocked”. Click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open. You only need to do this once.

Prefer the Terminal? This removes the quarantine flag and does the same thing:

xattr -dr com.apple.quarantine /Applications/Splash.app

Why trust it? Splash is fully open source: you can read every line of code in the repository, or build the app yourself with Xcode and skip this warning altogether. The release is built automatically by GitHub Actions from the tagged source.

Questions

macOS says it can't verify the app
That is normal for the alpha: follow the first launch guide. It takes four clicks, once.
Does it use my AI API key?
No. Splash has no API key field. The AI feature runs an agent CLI you already installed and signed in to (Claude Code works today), inside the scene's folder. What you type, and any drawing you send, go to that agent, as with any use of it.
Will it drain my battery?
A still wallpaper costs nothing and a loop costs very little. A live scene pauses on Low Power Mode by default, lowers its frame rate on battery, and stops when covered, when the screen sleeps or locks, and when the Mac is hot. You can change these in Settings.
Does it replace my current wallpaper?
While a scene is applied, Splash sets a picture of it as your wallpaper, so Mission Control and new displays match. It remembers the wallpaper you had, and “Put back my previous wallpaper” restores it. A dynamic or Aerial wallpaper can only be restored as a picture.
Why is a moving wallpaper a window?
macOS has no public way to play an animation as the wallpaper itself, so Splash puts a window at the desktop level, under your icons and windows. To limit the side effects it also sets a still picture as the real wallpaper, and the runner stays out of the Dock and the app switcher.
What does it do with my data?
Nothing leaves your Mac: no analytics, no telemetry, no accounts. The wallpaper process makes no network calls. A scene can only use the network if it asks for it. The only network use of the app itself is one small request to GitHub, once a day while the editor is open, to tell you about a newer version. You can switch it off in Settings.
How do I update?
When a new version is out, the app shows an Update button, and Settings → About has Update and restart: it downloads the release from this repository, checks it is signed with the same identity as your app, replaces it and opens it again, keeping your permissions. With Homebrew: brew upgrade --cask splash.
Is it really free?
Yes. It is free and open source under the GPL-3.0: you can use, study, modify and share it. If you share a modified version, it has to stay under the same license, with its source available.
